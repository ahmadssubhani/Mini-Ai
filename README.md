## About

Mini AI is a lightweight text summarization tool that uses AI to condense long-form text into clear, concise summaries. Designed to help users quickly extract key information from lengthy content — useful for research, content review, and everyday productivity.

## Features

- ✍️ Paste or input long-form text
- ⚡ Fast, AI-generated summaries
- 🎯 Clean, minimal interface
- 🤖 Powered by AI API integration for natural language understanding

## Getting Started

\`\`\`bash
git clone https://github.com/ahmadssubhani/Mini-Ai.git
cd Mini-Ai

pip install -r requirements.txt   # if Python backend
npm install                        # if there's a JS frontend

# Add your API key in a .env file:
# API_KEY=your_key_here

python app.py    # or the appropriate start command
\`\`\`

## How It Works

1. User pastes or inputs text
2. The app sends the content to the AI API for processing
3. A concise summary is generated and returned to the user
